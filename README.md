## 📚 Project Overview

This project presents an implementation of the CUSUM (Cumulative Sum) filter in Python, a statistical method used to detect structural breaks or regime shifts in financial time series. The CUSUM filter is particularly effective at identifying significant changes in the mean level of a process, making it a valuable tool for event detection, trend analysis, and signal generation in quantitative trading. 

By filtering out minor fluctuations, it helps reduce the number of false or noisy signals often produced by strategies based on moving averages, thereby improving decision-making in trading systems.
